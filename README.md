# 測驗練習應用程式 (Take the Test)

一個純前端、單一 HTML 檔案即可執行的線上測驗 / 刷題工具。使用者上傳自己的題庫檔案（CSV 或 XLSX），即可在瀏覽器中進行測驗、練習或讀題複習，無需任何後端伺服器或安裝流程。

## 功能特色

- **三種作答模式**
  - **測驗模式**：作答完所有題目後才顯示成績與結果。
  - **練習模式**：每題作答後立即點擊「確認答案」查看對錯與詳解。
  - **讀題模式**：不需作答，直接瀏覽題目並顯示正確答案與詳解，適合考前複習。
- **多科目支援**
  - **單一科目**：從上傳的題庫中選擇一個科目作答。
  - **多科目合併**：勾選多個科目，並自訂各科目在測驗中所佔的比例（自動以「平分比例」按鈕快速分配，或手動輸入百分比，總和須為 100%）。
- **題目類型篩選**：可選擇「是非題」、「選擇題」或「混合」出題，並可依答案內容（如是非題的 O/X、選擇題的特定選項）進行進階篩選。
- **靈活的出題範圍**
  - 全題庫：使用篩選後的所有題目。
  - 指定數量：從題庫中隨機抽取指定題數。
  - 指定範圍：依題號區間出題（僅限單一科目模式）。
- **測驗設定**：可自訂考試時間（分鐘，留空為無時間限制，剩餘 60 秒內顯示紅字提醒）與及格通過率（%）。
- **測驗結束後可選擇直接進入試卷檢討**，逐題顯示使用者作答、正確答案與詳解。
- **支援單選與複選題**：選擇題答案若包含多個選項（如 `1.3`），會自動切換為複選（checkbox）作答介面。
- **檔案格式自動辨識**：同時支援 `.csv` 與 `.xlsx`，並可一次上傳多個檔案；XLSX 檔案會依工作表名稱（含「是非題」或「選擇題」字樣）自動分類。

## 操作說明

1. 用瀏覽器開啟 `code_artifact.html`（無需伺服器，直接雙擊開啟即可，需能連上網路以載入 Tailwind CSS、PapaParse、SheetJS 等 CDN 資源）。
2. **上傳題庫檔案**：點擊「上傳您的題庫檔案」，可同時選取多個 CSV 或 XLSX 檔案。
3. **選擇模式**：測驗模式 / 練習模式 / 讀題模式，三選一。
4. **選擇科目**：單一科目或多科目合併（合併時需設定各科比例，總和必須為 100%）。
5. **選擇題目類型**：是非題 / 選擇題 / 混合，並視需要在「進階篩選」中勾選特定答案的題目。
6. **選擇範圍**：全題庫 / 指定數量（隨機抽題）/ 指定範圍（依題號，僅單一科目適用）。
7. **設定考試時間與通過率**（讀題模式不需要）。
8. 勾選是否於測驗結束後「直接檢討試卷」。
9. 點擊「開始」進入作答畫面；作答完成或時間到後會自動結算並顯示結果，也可選擇進入「試卷檢討」逐題核對詳解。

## 題庫檔案格式

題庫檔案為 CSV 或 XLSX，**檔名建議以「【科目名稱】」標示**（例如 `【資訊安全概論】.csv`），程式會自動擷取中括號內文字作為科目名稱；若檔名沒有中括號，則以檔名（去除副檔名）作為科目名稱。

### 共同欄位

| 欄位名稱 | 說明 | 必填 |
|---|---|---|
| 題型 | 內容須包含「是非」或對應「選擇題」關鍵字，用以判斷題目類型 | 是 |
| 題目 | 題目文字內容 | 是 |
| 答案 | 正確答案（見下方各題型說明） | 是 |
| 題號 | 題目編號（數字），用於「指定範圍」出題 | 選填，使用「指定範圍」時必填 |
| 解析 / 詳解 | 題目詳解說明，兩欄位擇一提供即可 | 選填（無則顯示「此題無提供詳解」） |

### 是非題

- **答案**欄位請填 `O`（正確／是）或 `X`（錯誤／非）。

### 選擇題

- 選項請放在 `選項1`、`選項2`、`選項3`、`選項4` 四個欄位中（可視實際選項數量增減，未填的選項欄位會被忽略）。
- **答案**欄位可用數字（`1`~`4`）或英文字母（`A`~`D`，大小寫皆可）表示，程式會自動轉換對應。
- 若為**複選題**，答案請以英文句點 `.` 分隔多個選項，例如 `1.3` 或 `A.C`，程式會自動切換為可複選（checkbox）作答介面。

### XLSX 檔案補充說明

- 工作表（Sheet）名稱需包含「是非題」或「選擇題」字樣，程式會依此自動分類題目至對應題型。
- 一個 XLSX 檔案內可同時包含多個工作表，分別對應不同題型。

### CSV 範例

```csv
題型,題號,題目,選項1,選項2,選項3,選項4,答案,解析
是非題,1,防火牆可以完全防止所有網路攻擊。,,,,,X,防火牆僅能過濾特定流量，無法防禦所有攻擊手法。
選擇題,2,下列何者為對稱式加密演算法？,AES,RSA,ECC,SHA-256,1,AES 為對稱式加密演算法；RSA、ECC 為非對稱式；SHA-256 為雜湊函式。
選擇題,3,下列何者屬於資訊安全三要素（CIA）？,機密性,可用性,完整性,以上皆是,4,CIA 三要素為機密性(Confidentiality)、完整性(Integrity)、可用性(Availability)。
```

## 技術架構

- 純前端單一 HTML 檔案（`code_artifact.html`），無需後端、無需安裝依賴。
- 使用 CDN 引入：
  - [Tailwind CSS](https://tailwindcss.com/)：畫面樣式
  - [PapaParse](https://www.papaparse.com/)：CSV 檔案解析
  - [SheetJS (xlsx)](https://sheetjs.com/)：XLSX 檔案解析
- 所有題庫資料與作答狀態皆保存在瀏覽器記憶體中，重新整理頁面後需重新上傳題庫。

## 注意事項

- 因使用 CDN 資源，執行時需要網路連線。
- 所有資料處理皆在本機瀏覽器端完成，題庫檔案不會上傳至任何伺服器，適合處理內部或私人題庫資料。
- 多科目合併測驗時，若「指定範圍」被停用，僅能使用「全題庫」或「指定數量」模式出題。
