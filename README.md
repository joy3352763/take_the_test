# 測驗練習應用程式 (Take the Test)

一個純前端的線上測驗／刷題工具。使用者上傳自己的題庫檔案（CSV 或 XLSX），即可在瀏覽器中進行測驗、練習或讀題複習；並內建語音朗讀、即時翻譯、多重外觀主題等輔助功能，無需任何後端伺服器或安裝流程。

## 功能特色

### 測驗核心
- **三種作答模式**
  - **測驗模式**：作答完所有題目後才顯示成績與結果。
  - **練習模式**：每題作答後立即點擊「確認答案」查看對錯與詳解。
  - **讀題模式**：不需作答，直接瀏覽題目並顯示正確答案與詳解，適合考前複習。
- **多科目支援**
  - **單一科目**：從上傳的題庫中選擇一個科目作答。
  - **多科目合併**：勾選多個科目，並自訂各科目在測驗中所佔的比例（可用「平分比例」按鈕快速分配，或手動輸入百分比，總和須為 100%）。
- **題目類型篩選**：可選擇「是非題」、「選擇題」或「混合」出題，並可依答案內容（如是非題的 O/X、選擇題的特定選項）進行進階篩選。
- **靈活的出題範圍**：全題庫／指定數量（隨機抽題）／指定範圍（依題號，僅單一科目適用）。
- **測驗設定**：可自訂考試時間（分鐘，留空為無時間限制，剩餘 60 秒內顯示紅字提醒）與及格通過率（%）。
- **支援單選與複選題**：選擇題答案若包含多個選項（如 `1.3`），會自動切換為複選（checkbox）作答介面。
- **檔案格式自動辨識**：同時支援 `.csv` 與 `.xlsx`，並可一次上傳多個檔案；XLSX 檔案會依工作表名稱（含「是非題」或「選擇題」字樣）自動分類。

### 作答輔助
- **測驗結束後可選擇直接進入試卷檢討**，逐題顯示使用者作答、正確答案與詳解。
- **🔁 錯題重考**：測驗結束後，若有答錯的題目，結果頁會出現「錯題重考」按鈕，可只針對答錯的題目重新測驗一次。
- **信心標記**：作答時可為每題標記「❓ 不確定」或「✅ 有把握」，方便複習時鎖定弱點題目。
- **📋 作答總覽**：以浮層方式呈現目前所有題目的作答狀態（已作答／未作答）與信心標記，可隨時開啟查看而不影響目前測驗進度。

### 語音與翻譯（新功能）
- **🔊 朗讀題目**：使用瀏覽器原生 Web Speech API，一鍵朗讀目前題目與所有選項；再次點擊即可停止朗讀。
- **⚙️ 朗讀設定**：
  - 語音選擇下拉選單，自動列出裝置可用語音，含「Google」字樣的語音會優先排列在最前面，預設嘗試套用「Google 國語（臺灣）」。
  - 語速滑桿（0.1 ~ 10）、音調滑桿（0 ~ 2），可依個人聽感喜好調整，設定會自動記憶。
- **🌐 翻譯題目**：使用 Google 翻譯端點即時翻譯目前題目與選項，結果顯示在題目下方的翻譯面板中。
- **⚙️ 翻譯設定**：可開啟「自動偵測語言」，並從下拉選單選擇要翻譯成的目標語言（預設為「中文(繁體)」，另支援簡體中文、英文、日文、韓文、越南文、泰文、西班牙文、法文、德文）。

### 外觀與介面
- **多重外觀主題**：內建 4 種佈景可一鍵切換，並可自訂專屬配色，設定會自動記憶於瀏覽器（`localStorage`）：
  - **預設（明亮）**：標準淡色介面。
  - **暗黑模式**：深色背景，適合夜間或光線昇暗環境使用。
  - **高對比模式**：黑底配高飽和色文字，加強可讀性。
  - **護眼模式**：豆沙綠背景，降低長時間閱讀的眼睛疲勞感。
  - 另可自訂背景、卡片、文字三種顏色，套用後同樣會被記住，下次開啟自動套用。
- **字體大小調整**：80% ~ 150% 可調整，方便不同螢幕或視力需求使用。
- **🛠️ 左下角整合浮動選單**：將外觀主題、作答總覽、朗讀題目、翻譯題目等工具按鈕整合收摸在畫面左下角單一入口，點擊 🛠️ 主按鈕即可展開／收合垂直選單，介面更簡潔。

## 操作說明

1. 用瀏覽器開啟 `index.html`（無需伺服器，直接雙擊開啟即可；需能連上網路以載入 Tailwind CSS、PapaParse、SheetJS 等 CDN 資源，以及使用翻譯功能）。
2. **上傳題庫檔案**：點擊「上傳您的題庫檔案」，可同時選取多個 CSV 或 XLSX 檔案。
3. **選擇模式**：測驗模式 / 練習模式 / 讀題模式，三選一。
4. **選擇科目**：單一科目或多科目合併（合併時需設定各科比例，總和必須為 100%）。
5. **選擇題目類型**：是非題 / 選擇題 / 混合，並視需要在「進階篩選」中勾選特定答案的題目。
6. **選擇範圍**：全題庫 / 指定數量（隨機抽題）/ 指定範圍（依題號，僅單一科目適用）。
7. **設定考試時間與通過率**（讀題模式不需要）。
8. 勾選是否於測驗結束後「直接檢討試卷」。
9. 點擊「開始」進入作答畫面。作答過程中可：
   - 點擊「信心標記」標示不確定或有把握的題目。
   - 透過左下角 🛠️ 浮動選單開啟「📋 作答總覽」查看目前進度，或使用「🔊 朗讀題目」「🌐 翻譯題目」輔助閱讀理解，也可從對應的 ⚙️ 設定入口調整語音／翻譯偏好。
10. 作答完成或時間到後會自動結算並顯示結果；若有答錯的題目，可點擊「🔁 錯題重考」只針對錯題再次練習，也可進入「試卷檢討」逐題核對詳解。
11. **切換外觀主題**：點擊左下角 🛠️ 浮動選單中的「🎨 外觀主題」，可隨時切換佈景（明亮／暗黑／高對比／護眼）、自訂顏色或調整字體大小，設定會自動儲存，下次開啟自動套用。

## 題庫檔案格式

題庫檔案為 CSV 或 XLSX，**檔名建議以「【科目名稱】」標示**（例如 `【資訊安全概論】.csv`），程式會自動擷取中括號內文字作為科目名稱；若檔名沒有中括號，則以檔名（去除副檔名）作為科目名稱。

### 共同欄位

| 欄位名稱 | 說明 | 必填 |
|---|---|---|
| 題型 | 內容須包含「是非」或對應「選擇題」關鍵字，用以判斷題目類型 | 是 |
| 題目 | 題目文字內容 | 是 |
| 答案 | 正確答案（見下方各題型說明） | 是 |
| 題號 | 題目編號（數字），用於「指定範圍」出題 | 選填，使用「指定範圍」時必填 |
| 解析 / 詳解 | 題目詳解說明，兩欄位擇一提供即可 | 選填（無則顯示「此題無提供詳解」） |

### 是非題

- **答案**欄位請填 `O`（正確／是）或 `X`（錯誤／非）。

### 選擇題

- 選項請放在 `選項1`、`選項2`、`選項3`、`選項4` 四個欄位中（可視實際選項數量增減，未填的選項欄位會被忽略）。
- **答案**欄位可用數字（`1`~`4`）或英文字母（`A`~`D`，大小寫皮可）表示，程式會自動轉換對應。
- 若為**複選題**，答案請以英文句點 `.` 分隔多個選項，例如 `1.3` 或 `A.C`，程式會自動切換為可複選（checkbox）作答介面。

### XLSX 檔案補充說明

- 工作表（Sheet）名稱需包含「是非題」或「選擇題」字樣，程式會依此自動分類題目至對應題型。
- 一個 XLSX 檔案內可同時包含多個工作表，分別對應不同題型。

### CSV 範例

```csv
題型,題號,題目,選項1,選項2,選項3,選項4,答案,解析
是非題,1,防火牆可以完全防止所有網路攻擊。,,,,,X,防火牆僅能過濾特定流量，無法防禁所有攻擊手法。
選擇題,2,下列何者為對稱式加密演算法？,AES,RSA,ECC,SHA-256,1,AES 為對稱式加密演算法；RSA、ECC 為非對稱式；SHA-256 為雜湊函式。
選擇題,3,下列何者屬於資訊安全三要素（CIA）？,機密性,可用性,完整性,以上皮是,4,CIA 三要素為機密性(Confidentiality)、完整性(Integrity)、可用性(Availability)。
```

## 技術架構

專案已拆分為三個檔案，方便維護與版本控管：

```
take_the_test/
├── index.html   # 頁面結構（HTML）
├── style.css    # 主題變數與樣式（CSS）
└── script.js    # 應用程式邏輯（JavaScript）
```

- **純前端架構**，無需後端伺服器、無需安裝依賴，開啟 `index.html` 即可執行。
- **CDN 引入的第三方套件**：
  - [Tailwind CSS](https://tailwindcss.com/)：畫面樣式（透過 CDN 版本，僅適合展示/個人使用，正式產品環境建議改用建置流程）
  - [PapaParse](https://www.papaparse.com/)：CSV 檔案解析
  - [SheetJS (xlsx)](https://sheetjs.com/)：XLSX 檔案解析
- **瀏覽器原生 API**：
  - `SpeechSynthesis` / `SpeechSynthesisUtterance`（Web Speech API）：朗讀題目功能。
  - `fetch` 呼叫非官方 Google 翻譯端點 `translate.googleapis.com/translate_a/single`：翻譯題目功能（僅供個人學習用途，非官方 API 無 SLA 保證）。
- **狀態管理**：題庫資料與作答狀態皮保存在瀏覽器記憶體中，重新整理頁面後需重新上傳題庫；主題、字體大小、語音與翻譯偏好等設定則存於 `localStorage`，會在下次開啟時自動套用。
- **程式碼設計**：主題樣式、回馈訊息格式化、答案顯示格式化等重複邏輯已抽出為共用函式（如 `safeStorage`、`formatCorrectAnswer`、`formatUserAnswer`、`buildFeedbackHtml`），並以 CSS class 管理主題樣式，降低重複度、提升可維護性；新功能（浮動選單／朗讀／翻譯）的初始化程式碼目包裹於 `try/catch` 並加上元素存在性檢查，避免單一功能異常時影響題庫上傳與測驗等核心功能。

## 注意事項

- 因使用 CDN 資源與翻譯／語音相關功能，建議在有網路連線的環境下使用；朗讀功能需瀏覽器支援 Web Speech API（多數現代桌上瀏覽器皮支援）。
- 所有題庫與作答資料皮在本機瀏覽器端處理，不會上傳至任何伺服器，適合處理內部或私人題庫資料；翻譯功能會將題目文字送往 Google 翻譯端點，若題庫內容涉及機密資訊，請留意此限制。
- 多科目合併測驗時，若「指定範圍」被停用，僅能使用「全題庫」或「指定數量」模式出題。
- 主題、字體大小、語音與翻譯偏好設定目存於瀏覽器的 `localStorage`；若瀏覽器處於無痕模式或封鎖本機儲存功能，設定將無法保存，但不影響測驗功能本身的正常使用。
- 若透過 GitHub Pages 部署，推送更新後 CDN 快取可能需數分鐘才會生效，如發現網頁未反映最新修改，請嘗試強制重新整理（Ctrl+Shift+R）或稍候重試。
